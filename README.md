# DDL 任务记录器 · iPad 离线网页版

在 iPad 的 Safari 打开 [网页版](https://manyxu123.github.io/ddl-ipad-calendar/)，等待页面显示“离线界面已就绪”，然后点“分享”→“添加到主屏幕”。首次打开需要联网；缓存完成后可离线使用。

任务保存在 iPad 本机的 IndexedDB，不会自动同步到 Mac。请定期使用应用内的“导出备份”保存 JSON 文件；“导入备份”会替换当前设备上的任务。

macOS 软件版请到 [Mac App 仓库](https://github.com/ManyXu123/ddl-macos-app)下载。目前提供 Apple Silicon（arm64）版本。两版可通过 JSON 备份迁移任务。

本仓库只包含网页版的静态文件，不包含个人任务或数据库。
